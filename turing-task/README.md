# turing-task

Resources and guidelines for building, validating, and reworking SciCode-style benchmark tasks for Turing / CTP physics benchmarks.

## Repository Contents

- `scicode-task-builder (3).skill`: Packaged `.skill` archive for AI agents (Antigravity / Claude).
- `scicode-task-builder/`: Extracted skill folder containing:
  - `SKILL.md`: Core instructions, pod-lead rules, notebook structure, validator error resolutions, and Pass@k calibration guidelines.
  - `references/difficulty-levers.md`: Battle-tested difficulty traps and discriminative test patterns.
  - `assets/new-task-template.md`: Planning worksheet for new tasks from research papers (Path B).
  - `assets/rework-input-template.md`: Worksheet for diagnosing and reworking existing tasks (Path A).
